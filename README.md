# eMenu POS Prototype — Starbucks JLT

An interactive handheld POS prototype for the UAE market, focused on the table
settlement flow (find table → review bill → tip → collect payment). Single-file
HTML/CSS/JS, no build step.

**Live demo:** https://balaak.github.io/emenu-pos-prototype/

Tip: use the **Flow** button (bottom-right) to jump to any screen or edge state
(card declined, network timeout, table locked, no open bill, etc.).
